# Sources

All law texts in this folder are the official, verbatim texts published by the
German Federal Ministry of Justice on
[gesetze-im-internet.de](https://www.gesetze-im-internet.de/), downloaded as
XML and converted to markdown without summarizing or rewriting. Each file
states its retrieval date and source URL at the top.

| File | Law | Source |
|---|---|---|
| `bgb_mietrecht.md` | Bürgerliches Gesetzbuch, tenancy law, §§ 535–580a | <https://www.gesetze-im-internet.de/bgb/BJNR001950896.html> |
| `kschg.md` | Kündigungsschutzgesetz (dismissal protection) | <https://www.gesetze-im-internet.de/kschg/BJNR004990951.html> |
| `burlg.md` | Bundesurlaubsgesetz (statutory leave) | <https://www.gesetze-im-internet.de/burlg/BJNR000020963.html> |
| `entgfg.md` | Entgeltfortzahlungsgesetz (continued pay on holidays/illness) | <https://www.gesetze-im-internet.de/entgfg/BJNR106500994.html> |

All four were retrieved on 2026-10-14.

## Copyright

Under German law, official texts such as statutes are generally not
copyright-protected (§ 5 Urheberrechtsgesetz — UrhG, "amtliche Werke"). The
gesetze-im-internet.de site is run jointly by the Federal Ministry of Justice
and Juris GmbH; see their own legal notice for details:
<https://www.gesetze-im-internet.de/impressum.html>.

These texts may be out of date by the time you read this — always check
gesetze-im-internet.de for the current version before relying on anything
here for an actual legal question. This project is a portfolio demo, not a
source of legal advice.
